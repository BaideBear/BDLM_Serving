## 0. 结论摘要（先给判断）

**一句话：** 三个问题都不应再开一张大矩阵。先把“尾部”做成头块选位冻结的单变量实验；把“2B”当成独立容量档而不是 B 的别名；把“刷新:MASK”先当诊断量而不是控制目标。三件事通过后，才允许用公平的升/降档快照对照去探索相对更优的预算路径。

**我的首选：**

1. **跨块尾部：不做默认竞争者。** LLaDA 在 Q64、Gemma 在 Q512 各做一个“头块选位冻结、余量只建尾块 KV、当轮不采样尾块”的最小实验；尾块采样单独作为投机臂。用“同物理 Q 的头块重读对照”隔离尾块的信息价值。我的先验是：尾块 KV 会被头块提交/encoder 重编码大面积作废；尾块采样还会在降档时留下 dirty 债务。若尾块 KV 有效率 <50%、尾块 token 交付率 <50%、撤销率 >20%，或同 Q 下质量/TPF 无增益，淘汰。
2. **2B FlowBlock 单向块因果：2B 是容量档，不是 B 的别名。** 先证明 2B 联合块因果前向相对“两个 B 顺序前向”在同物理 Q 下有 TPF 增益，且相对单块 B 在质量/TPF 上有非支配收益；否则 2B 不作为默认。FlowBlock W2 只作外部参照，不作机制对照（采样器、提交、RNG 都不同）。我的先验是：LLaDA 2B 只买到 TPF、买不到质量；Gemma 2B 在 active-only 后才接近 W1，仍不是默认。
3. **刷新:MASK：先测分布，再试 β=0.5 的刷新上限。** 低档刷新占比高（LLaDA Q4 的 R/M≈1.23、Gemma Q32≈0.60；Gemma Q32 有 42.4% 的 forward 是只刷新/终检），纯排水轮不推进采样。首选干预是“每轮至少给 MASK 留 β·Q，刷新欠账结转不丢”，在低档做 β=0/0.25/0.5/0.75 的单变量对照；若不能减少纯排水轮，或不能在同总 Q 下改善质量/TPF，淘汰。比例本身只有通过“同快照升/降档边际价值”检验后，才允许作为切档信号。
4. **任意切档：** 先把 `step(state, q_t)` 的状态合同、转移矩阵和“同快照分支”做出来；同名义报价不等于同物理工作，升/降档对照必须在同一状态快照上分支。路径探索放在最后，且只在上述三个机制至少一个通过后进行。

**阶段门：** Phase 0 状态合同/遥测/转移矩阵 → Phase 1 尾部 → Phase 2 2B → Phase 3 刷新:MASK → Phase 4 路径。Phase 1–3 未通过时，不进入 Phase 4；固定档 K0/IBS 仍是默认，负结果照实报告。

**与复盘的关系：** 我同意 `BLOCK_ABLATION_POSTMORTEM.md` 终止 00/10/11、不补矩阵的判断；也同意“后块不是默认竞争者”“q=2B 三组退化到同一路径，不能解释为开关效应”。我不建议按复盘里的“LLaDA Q16 有界复核、Gemma Q128 同一 forward logits”直接开新矩阵，而是先把尾部、2B、刷新:MASK 拆成三个可证伪的单变量闸门；复盘的建议可以在闸门通过后作为机制解释，而不是替代闸门。

## 1. 问题、边界与不变量

### 1.1 单请求与任意切档合同

- 单请求、batch=1；两个模型：LLaDA2.1（B=32）、DiffusionGemma（B=256）。
- 外层每轮给 `q_t`，执行器只实现 `step(S_t, q_t) -> (S_{t+1}, event_t)`；`q_t` 可在档位集合内任意跳变，包括相邻升/降、跨档跳变、2B、抖动、2B→低档、低档→2B。执行器不挑周期、不强制下一档、不因切档清空 KV/RNG/dirty。
- 档位集合：LLaDA {4, 8, 16, 32, 64}；Gemma {32, 64, 128, 256, 512}。2B 是独立容量档，不是 B 的别名；单块执行器收到 2B 必须拒绝或走双块路径，不能静默做成 B。
- 指标：正确数/90；宏 TPF `mean_i(N_i/F_i)`；token efficiency `ΣN/ΣQ_selected_prefix_KV`；物理效率 `ΣN/ΣQ_physical`；实际 decoder/encoder Q、F、N、截断/失败；每轮实际 Q、必刷超额、峰值 Q。名义 Q 不等于物理 Q；同一报价序列不等于同一物理工作。
- 不在范围：多请求排布、负载策略、准入、服务时延 SLO、kernel 微基准。TPF 是逐请求 tokens/forward 的算术平均，不是 tokens/s。
- 固定档实验只用于机制隔离，不代表部署只跑固定档；任意切档的资格由 Phase 0 的状态合同/转移矩阵和 Phase 4 的路径对照验证。

### 1.2 状态向量与转移不变量

状态 `S_t` 至少包含：

- 请求/模型标识、phase（prefill/denoise/verify/commit/reencode/done）、当前物理块 index、committed_end、context_version；
- 每个驻留块的 KV（层、行、版本）、tokens、accepted mask、draft/self-conditioning、采样年龄、post-step 计数、停止历史；
- 每块 dirty 集合（上次写入未重读的行）、last_write/last_query 时钟、pending refresh 债务；
- 每块 RNG 流（或可验证的头块 RNG 摘要）、selection_seed、offer_tick；
- EOS/长度上限、尾块驻留/停放状态、encoder 重编码版本。

不变量（任何切档都必须成立）：

1. **dirty 不丢**：上轮新解码/严格编辑的行必须进入待刷；若 `dirty > q_t`，按实付费并结转，纯排水轮也记 forward；不允许跳过欠账继续采样。
2. **KV 版本**：行的 KV 只有在 context_version 匹配时才可读；头块提交/encoder 重编码后，尾块旧 KV 失效，晋升前必须重新验证/重编码；不得免费用一次 `B×H` 起步。
3. **采样合法性**：只有有效历史、原生规则允许的行可采样/T2T；不选历史 Q 不等于冻结本地 token；不用未来 logits；未选且已初始化的 KV 保持可见。
4. **尾块停放**：降档时尾块暂停，保留 tokens/acceptance/RNG/年龄；低档不采样尾块；上档后仍用原尾块，晋升前在新前缀下重新验证；尾块提前宣告 done 不能直接提交。
5. **提交/EOS**：头块只有无 MASK、无未刷 token 写入时才退休；尾块不能先于头块提交；EOS 右侧丢弃的工作照收；不改变原生采样/停止语义。
6. **RNG 隔离**：尾块动作不能推进头块的 RNG 流；尾块采样用独立流；降档不重置种子；头块 RNG 摘要在尾块动作前后必须一致（尾部单变量实验的硬条件）。
7. **计费**：所有物理投影（含 bootstrap、verify、commit、reencode、Gemma encoder）都记账；必刷超额单列；不把纯 prompt prefill 混入生成 F/Q。

### 1.3 公平对照的三条规则

- **同状态**：比较双方在干预前必须逐步一致（tokens、选位、KV 版本、RNG、dirty、计数）；用 state digest 或重放到同一 tick 验证；首个分歧必须落在预期干预轮。
- **同物理工作或明确标注差异**：同名义 Q 不等于同物理 Q；能匹配物理 Q 时用匹配对照（如同 Q 的头块重读），不能匹配时报告 Pareto 与额外 Q，不宣称等成本胜利。
- **同评分/同区间**：同 frozen90、同种子、同 max length/EOS/scorer；报 original30/new60/full90、逐题救/丢、配对区间；30 题只做淘汰，不宣告优胜；不事后挑档位/相位/阈值。

### 2.5 切档与路径

- LLaDA 16/32n：固定 Q16 76/4.888/222,550；固定 32n 75/5.677/261,824；16,16,32n,32n 71/5.246/246,091；32n,32n,16,16 70/5.342/257,237。交替 TPF 在端点之间，但正确数低于两个端点；不能用平均预算插值质量，缓存可复用也不等于切档对质量无影响。
- Gemma 32/64：固定 A 83/8.463/240,190；AABB 82/10.472/254,468；BBAA 83/10.559/260,838；固定 B 83/12.897/250,795。混合总 Q 高于固定 64；非选位环节（bootstrap/verify/reencode）约占 48%/47%。
- Gemma 128/256n：固定 L 84/17.437/285,967；固定 H 85/25.510/357,632；128→256n 84/21.226/321,377；256n→128 84/18.406/320,987。混合没有更好。
- Gemma 高档消融：HHLL 86/22.357/346,119；HLLL 85/19.553/312,950；LHLL 84/19.394/313,822；固定 L 84/17.437/285,967；固定 H 85/25.510/357,632；受限 IBS HHLL 80/18.898/289,152。HLLL 对 HHLL 少 33,169 Q、多 77 F、救0丢1；对混合受限 IBS 多 5 题、TPF 高 0.656、总 Q 多 8.23%。是取舍，不是支配。
- 按剩余 MASK 门控：all 86/22.357/346,119；gate_early_high 86/20.300/327,295；gate_tail_high 84/19.574/286,607；gate_tail_low 85/18.754/325,515；gate_early_low 83/18.916/311,430。门控省 Q 但丢 TPF/质量，没有免费午餐；这直接说明“状态信号可以换成本，但不能自动改善前沿”。
- 最近物理 Q 匹配：总量相近不等于逐题分配相同；相对 OBS 固定128，混合 15 题更省、3 题相等、72 题用更多 Q；相对 IBS 高档先行，固定稀疏128 44 题更省、46 题用更多 Q。不要称等成本。
- **读法：** 混合路径不是免费的；同名义序列不等于同工作；路径效应被状态历史混杂。公平方式是“转移用同快照分支、路径用同初始状态 + 同报价多重集/匹配总 Q”。门控结果说明状态信号能换成本，但不能自动改善前沿。

### 2.6 证据边界

- 跨硬件（H800 vs A800）会改变一题；不要把细小差异归因算法。
- 不同采样器/提交（FlowBlock vs 原生、IBS vs OBS）不是机制对照。
- 90 题、配对区间、多重比较；30 题只做淘汰。
- “零可见机会”不是零效应；单块档不能测跨块掩码。
- CPU 信号未必在 GPU 复现（28/30 vs 25/24 的例子）。
- 不从输出反推“当时能看到”的 logits；用掩码 witness 和首分歧。
- 名义 Q、物理 Q、token efficiency 口径不同；Gemma 总 Q 含 encoder，不能直接用总 Q/F 判断 decoder 限额。

## 3. 三个研究问题与假设

### Q1 跨块尾部

- **H1a（LLaDA）：** Q64 下，头块选位冻结为 Q32；用余量 Q32 只建尾块 KV（不采样尾块），相对“同物理 Q 的头块重读对照”不降质量，并在同物理 Q 下降低每交付 token 的 forward 或提高 TPF。
- **H1b（Gemma）：** Q512 下，头块整块 256 不变；用余量 256 只建尾块 KV（不采样尾块），相对同 Q 头块重读对照不降质量，并降低尾块 bootstrap/重编码成本或提高 TPF。
- **H1c（两者）：** 尾块采样（投机 token）只有在尾块 token 存活到交付时才增值；若存活率低，或降档 dirty 债务饿死头块，则尾块采样有害。
- **H1d：** 头块还有可推进/可复核位置时，余量应优先给头块（fill-head），尾块只应在头块没有合格工作时考虑。
- **先验：** H1a/H1b 可能失败，因为头块提交/encoder 重编码会作废尾块 KV；H1c 可能失败于存活率/债务；H1d 可能成立。实验是为证伪尾块，不是为救尾块。

### Q2 2B FlowBlock 单向块因果

- **H2a：** 联合 2B 块因果前向相对“两个 B 顺序前向”在同物理 Q 下提高 TPF，且不降质量。
- **H2b：** snapshot 语义（后块读前块轮初旧 KV）比 live 更安全；live 可能更新鲜但带来更多分歧/编辑。若 live 不更好，保留 snapshot。
- **H2c：** 2B 只有在后块真正活跃时才值得；否则单块 B 更便宜且等价。active-only 投影在匹配或更低 Q 下优于全 2B。
- **H2d：** FlowBlock W2 的表面优势部分来自采样器/提交/RNG 差异；控制这些后，2B 的增益更小或消失。
- **先验：** H2a 可能对 TPF 成立、对质量不成立；H2c 可能成立；H2d 可能成立。2B 不是默认质量/成本赢家。

### Q3 刷新:MASK 比例

- **H3a：** 低档下 dirty 刷新占主导并造成纯排水轮；给 MASK 留最低份额（β>0）并结转欠账，可减少纯排水轮，并在同总物理 Q 下改善质量/TPF。
- **H3b：** 比例只有在“高 R/M 预测更高 offer 的更大边际收益”时才是有用的切档信号；否则只是成本诊断。
- **H3c：** 大部分刷新是强制欠账，不是可选前缀；KV-only 前缀刷新的直接质量效应很小。不要混为一谈。
- **先验：** H3a 可能在低档成立但有 stale KV 风险；H3b 未证；H3c 可能成立。第一步是遥测，不是干预。

## 4. 首选实验设计

### 4.0 Phase 0：状态合同、遥测、转移矩阵（必须先做）

- 实现并验证 `step(S,q)` 覆盖全部档位与任意序列；no-op 可复现；state digest；全档位对的转移矩阵；dirty/RNG/KV 不变量；掩码 witness；尾块命运账本；逐轮 R/M。
- Phase 0 不做质量结论，只是资格门。
- 退出条件：全部转移测试通过；no-op 逐位一致；重放 state digest 一致；逐轮账本与物理 Q 对账。

### 4.1 E1 LLaDA 跨块尾部（B32，Q64）

**臂：**

- `L0` Q32 头块-only 对照（无余量）。
- `L1` Q64 同物理 Q 头块重读对照：头块选位与 L0 完全相同；余量 Q32 用于重读头块行（KV-only，不采样，不改变状态）。这是与尾块臂同 Q 的干净对照，隔离尾块的信息价值。
- `L2` Q64 尾块 KV-only：头块选位与 L0 完全相同；余量 Q32 投影整块尾块 B32，不采样尾块，尾块不消耗 RNG；尾块 KV 在头块提交时失效；晋升时重编码。
- `L3` Q64 尾块采样：同 L2，但尾块用独立 RNG 流采样；尾块 token 发布；dirty 债务记账；降档时先还债。
- `L4` Q64 fill-head：余量 Q32 用于补头块 MASK/前缀（若头块稀疏）；检验余量是否应给头块。
- `L5` Q64 尾块采样 + 降档：尾块采样 k 轮后降到 Q8/Q16；测尾块 dirty 债务、纯排水轮、头块推进和最终质量。检验尾块采样的隐藏成本。

**物理 Q 匹配细则：** L0/L1/L2/L3 的头块选位完全相同；尾块臂的总投影 = 头块行数 + 尾块 B 行；对照用同样数量的头块重读行匹配总投影。若头块选位少于 B 行，尾块臂只用 B 行尾块，剩余 Q 不强行凑满；对照也同样不凑满。这样 L2/L3 对 L1 是同物理 Q，L2/L3 对 L0 的差额是尾块的额外成本。
**固定：** prompt、seed、模型/数值、头块选位顺序/RNG、采样阈值、提交/EOS、最大长度。
**主指标：** 实际物理 Q 下的正确数、宏 TPF、token efficiency；L2/L3 对 L1 同 Q；L2/L3 对 L0 的额外 Q 用 Pareto 报。
**尾块遥测：** 尾块投影行、晋升时 KV 有效行、尾块首解 token、最终交付 token、撤销/编辑 token、丢弃行、晋升重编码行、降档 dirty 债务、尾块窗口轮数、头块 RNG 摘要、首分歧。
**淘汰：** L2/L3 在 ≤+5% Q 下对 L1 质量/TPF 无增益；或尾块 KV 有效率 <50%；或尾块交付/首解 <50%；或撤销/首解 >20%；或 L4 更好；或 L5 显示尾块债务饿死头块。
**样本：** 原30 预登记淘汰；有信号才 90；配对救/丢与区间；同种子。

### 4.2 E2 Gemma 跨块尾部（B256，Q512）

**臂：**

- `G0` Q256 原生（W1）对照。
- `G1` Q512 同物理 Q 头块重读对照：头块整块 256 + 一次 256 行 no-op 头块重读（KV-only，不采样）；物理 Q 512；隔离尾块。
- `G2` Q512 尾块 KV-only：头块整块 256 + 尾块整块 256，不采样尾块；尾块 KV 在 encoder 重编码时失效；晋升时重验证。
- `G3` Q512 尾块采样：同 G2，但尾块用独立 RNG 采样；dirty 债务记账。
- `G4` Q512 active-only 2B：只投影活跃块；尾块闲置时只算头块；块因果掩码。
- `G5` Q512 全 2B / FlowBlock W2 外部参照（采样器/提交/RNG 不同）。
- `G6` Q512 snapshot vs live（子实验；若 snapshot 不可实现，标 N/A，不伪造）。
- `G7` Q512 尾块采样 + 降档：尾块采样 k 轮后降到 Q32/Q64；测尾块债务/纯排水/头块推进。

**物理 Q 匹配细则：** G1 的 256 行 no-op 头块重读与 G2/G3 的 256 行尾块投影在物理 Q 上匹配；G0 是半 Q 对照，只作 Pareto 参考，不宣称同成本。
**固定：** prompt、seed、模型/数值、头块整块 256 选位、开块阈值 0.8、encoder 重编码、提交、采样。
**主指标：** 实际 Q 下正确数、TPF、token efficiency；G2/G3 对 G1 同 Q；G2/G3 对 G0 的额外 Q 用 Pareto；G4 对 G2/G3。
**尾块遥测：** 加 encoder 重编码 Q（每次 256 行）、尾块 KV 有效率、重编码行。
**淘汰：** G2/G3 在 ≤+5% Q 下对 G1 质量/TPF 无增益；或对 G0 的额外 Q 不划算；或尾块 KV 有效率 <50%；或重编码行 >50% 尾块行；或 G3 不优于 G2；或 G7 显示尾块债务饿死头块。
**样本：** 原30 预登记；有信号才 90。

### 4.3 E3 2B 联合块因果（LLaDA Q64，Gemma Q512）

**臂（同状态、同物理 Q=2B）：**

- `C0` 顺序 2×B：两个独立 B 前向，无联合掩码；总 Q 相同。
- `C1` 联合 2B，块因果，live（当前语义）。
- `C2` 联合 2B，块因果，snapshot（若可实现：后块读前块轮初旧 KV）。
- `C3` 联合 2B，无跨块掩码（仅诊断；若模型要求块因果，则不是合法候选）。
- `C4` 单块 B 全读（C=B 端点，即 2B 别名）。
- `C5` FlowBlock W2 外部参照（采样器/提交/RNG 不同）。

**固定：** 同状态、同物理 Q、同采样器/提交（C5 除外）、同 RNG 流、同掩码语义。
**主指标：** TPF、质量、物理 Q；C1/C2 对 C0 同 Q；C1/C2 对 C4 不同 Q 用 Pareto；C5 只作外部。
**诊断：** 掩码 witness（扰动后块，前块输出不变；扰动前块，后块输出可变）；live vs snapshot 首分歧层；左右 logits 最大绝对差；token 存活；与 C5 的 RNG/提交差异。
**淘汰：** C1/C2 在同 Q 下 TPF 不高于 C0；或质量/TPF 不高于 C4；或 C3 更好（说明掩码有害，但 C3 不是合法候选）；或 C5 的增益只来自采样器/提交。
**样本：** 原30 预登记；有信号才 90。

### 4.4 E4 刷新:MASK 比例（两模型，低档）

**第一步：观测。** 逐轮记录 `R_t`（dirty/强制刷新行）、`M_t`（MASK 行）、`P_t`（可选前缀）、`C_t`（冷行）、`D_t`（轮前债务）、`D_{t+1}`（轮后债务）、`ρ_t=R_t/(R_t+M_t)`；按档位/模型/phase/路径报分布；识别纯排水（`M_t=0`）、刷新受限（`ρ_t>0.5`）、推进（`ρ_t<0.5`）；与 `refresh-attribution.csv` 的聚合对账。

**第二步：干预（固定档、低档）。**

- `R0` 对照：当前 `choose`（dirty 优先，无上限）。
- `R1` β=0.25、`R2` β=0.5、`R3` β=0.75：每轮给 MASK 留 `ceil(β q)`；最多 `q - mask_budget` 给 dirty；欠账结转；若 `|MASK| < mask_budget`，余量给 dirty/前缀。
- 固定：档位、MASK 份额的头块选位顺序、RNG、采样、提交。

**主指标：** 同总物理 Q 下质量、宏 TPF、token efficiency；纯排水轮、债务年龄、峰值 Q、截断。
**诊断：** stale KV 暴露（已解码行 KV 未刷的轮数）、首分歧、刷新归因（required vs prefix vs old backfill vs verify）、严格 T2T。
**第三步：切档信号（仅在第二步通过后）。** 在同快照分支 high vs low offer，检验高 `ρ_t` 是否预测更高 offer 的更大边际收益；预登记阈值；若不预测，不作为切档信号。
**淘汰：** β>0 不能减少纯排水轮，或同 Q 下质量/TPF 不优于 R0，或截断/峰值 Q 上升；或 `ρ_t` 不预测边际价值。
**样本：** 原30 预登记；有信号才 90；逐轮账本。

### 4.5 实验顺序与阶段门

- Phase 0 → E1/E2（尾部）→ E3（2B）→ E4（刷新）→ Phase 4（路径）。
- 每个 E：原30 预登记淘汰；有信号才 90；配对区间；不事后挑档位/相位/阈值。
- Phase 4 门：E1–E4 至少一个通过预登记主指标且物理 Q 审计通过；否则报负结果，固定档 K0/IBS 仍是默认。
- **“上述问题解决后才探索相对优秀的路径”**：Phase 4 只在 E1–E4 之后；不用路径搜索去救一个失败的机制。

## 5. 反证实验

对每个假设，预先写明“什么观察会推翻它”：

- **H1：** L2/L3 在匹配 Q 下质量 ≤ L1 且 TPF ≤ L1；或尾块 KV 有效率 <50%；或尾块交付/首解 <50%；或撤销/首解 >20%；或 L4 更好；或 L5 尾块债务饿死头块。
- **H2：** C1/C2 在同 Q 下 TPF ≤ C0；或质量/TPF ≤ C4；或 C3 更好（掩码有害）；或 C5 的增益可由采样器/提交解释。
- **H3：** β>0 不减少纯排水轮；或同 Q 下质量/TPF ≤ R0；或截断/峰值 Q 上升；或 `ρ_t` 不预测边际价值。
- **Null 对照：** 同 offers/seed 的 no-op 运行必须逐位一致；若不一致，比较无效，不是负结果。
- **对抗案例：** 长生成、多编辑、提前 EOS、尾块重、剩余 MASK 少、context version 变化、2B→低、低→2B。

## 6. 诊断与遥测

- **逐轮账本：** `tick, offer, q_actual, block, phase, R_t, M_t, P_t, C_t, D_before, D_after, tail_state, tail_rows, tail_sampled, tail_revoked, tail_discarded, context_version, forward_type, physical_Q, encoder_Q`。
- **尾块命运账本：** 每个尾块首解 token 跟踪到最终输出：交付/编辑/撤销/EOS 外丢弃/晋升重算；每个尾块投影行跟踪到晋升：KV 有效/失效/重编码。
- **掩码 witness：** 在第一层实际加性 mask 上核对方向；扰动后块验证前块不变；扰动前块验证后块可变；不只看 `pair=True` 标签。
- **首分歧：** 配对臂找到第一个选位/logits 不同的轮；验证它落在预期干预轮；若更早分歧，比较无效。
- **刷新归因：** required vs prefix vs old backfill vs verify；严格 T2T vs KV 刷新；不要用刷新次数代替质量。
- **2B 语义：** live vs snapshot 的首分歧层、左右 logits 最大差、token 存活；FlowBlock 的 RNG/提交差异单列。
- **工作分解：** 按 phase（选位/bootstrap/verify/commit/reencode）和按档位分解总 Q；路径的总 Q 不等于各档名义 Q 之和。
- **状态摘要/重放：** state digest 或重放到同一 tick；验证 tokens/KV/RNG/dirty/计数一致。
- **统计：** 配对分层 bootstrap/区间；90 题；30 只淘汰；多重比较注明；不把不显著写成等效。

## 7. 淘汰条件

- **全局无效：** 物理 Q 审计失败、dirty 行丢失、采样/提交语义改变、RNG 泄漏、no-op 不可复现。先修实现，不解读分数。
- **尾部：** ≤+5% Q 下质量/TPF 无增益；尾块 KV 有效率 <50%；交付/首解 <50%；撤销/首解 >20%；fill-head 更好；尾块窗口 <2 轮；尾块债务饿死头块。
- **2B：** 同 Q 下 TPF 不高于顺序 2×B；质量/TPF 不高于单块 B；增益只来自 FlowBlock 采样器/提交；live 不优于 snapshot。
- **刷新：** 不减少纯排水轮；同 Q 下质量/TPF 无增益；截断/峰值 Q 上升；比例不预测边际价值。
- **路径：** 在匹配 Q 下被固定档或受限 IBS/OBS 支配；不报为赢家。
- **停止规则：** 原30 无信号不扩 90；90 无信号不事后调阈值；不把“接近”写成“通过”。

## 8. 升/降档状态与路径的公平对照

### 8.1 状态快照与转移矩阵

- **快照：** 在冻结轨迹的 `t0` 保存/重放完整状态；用 state digest 验证 tokens、KV 版本、RNG、dirty、计数一致；然后分支。
- **转移矩阵：** 对每个档位对 `(a,b)`，从同一状态施加 `b`；检查不变量；与“从同快照固定跑 b”的前 k 轮比较，分离“转移效应”和“档位效应”。
- **升/降/保持分支：** 在同一 tick 分支为 up（h）、down（l）、stay（s）；之后给同一报价序列 k 轮；比较每轮 Q/债务/尾块/R-M 和最终质量/TPF。
- **降档要点：** 停放尾块，保留 tokens/acceptance/RNG；先还 dirty；债务 > q 时纯排水；上档后重新验证尾块；不免费复用旧 KV。
- **升档要点：** 复用状态；2B 联合刷新两块；尾块采样只在合法时；不清空。
- **跳变：** 同升/降，但可跳过中间档；不伪造中间档工作。

### 8.2 路径对照协议

- **路径 = 报价序列。** 同初始状态/seed/模型；同报价多重集或匹配总 Q；报每轮工作和状态；不与转移效应混。
- **路径族：** 固定低/高/2B；AABB/BBAA；跳升/跳降；锯齿；dwell；状态自适应（仅在 E4 验证后）。
- **公平清单：**
  1. 同 frozen90/seed/scorer；同 offers 或匹配 Q；不事后挑档位/相位。
  2. 报质量/TPF/效率/Q/F/N/截断；配对救/丢/区间。
  3. 工作分解按 phase 和档位；路径总 Q 不等于名义 Q 之和。
  4. 报“状态被带入下一档”的情况：尾块驻留、dirty 债务、context version；早拿高档可能占状态优势。
  5. 同名义序列与同物理 Q 分开报；总量相近不等于逐题相近。
  6. 跨模型不比绝对 TPF/效率；跨硬件不把细小差异归因算法。
  7. 统计：配对分层 bootstrap；90 题；30 只淘汰；多重比较注明。
- **校准案例（不是证明）：** Gemma 32/64 AABB/BBAA；LLaDA 16/32n；最近物理 Q 匹配；HHLL/HLLL/LHLL；按剩余 MASK 门控。它们说明混合路径不是免费的，状态信号可以换成本但不自动改善前沿。

### 8.3 阶段门

- Phase 4 只在 E1–E4 之后；若都未通过，报负结果，固定档 K0/IBS 仍是默认。
- **“相对优秀的路径”** 定义为在（质量、TPF、物理 Q）上相对固定档和受限 IBS/OBS 非支配，不是单一标量。
- 不用路径搜索救失败机制；不把“平均预算插值”当质量预测；不把“缓存可复用”当质量无损。

## 9. 交付物、风险与边界

**交付物：** 状态合同测试、逐轮账本、配对报告、图、决策备忘录；每个 E 的原30/新60/全90、N/F/Q、救/丢、区间。

**风险：**

- 采样器/提交/RNG/硬件混杂；FlowBlock 不是机制对照。
- 2B 别名：C64=C32、C512=C256；不要把别名当新点。
- 尾块浪费：提前解出/撤销/重算/EOS 外丢弃；不把投影行当交付。
- 刷新：强制欠账 vs 可选前缀；不要混。
- 掩码开关会改变轨迹；质量差不是纯掩码效应；用首分歧和触发分层。
- 任意切档的状态历史；同报价序列不等于同工作。
- 统计功效：90 题、配对区间、多重比较；30 只淘汰。

**不要做：**

- 不重开 00/10/11 矩阵；不把 10 的多变量变化当跨块效应。
- 不把 FlowBlock W2 当机制对照；不把 C64/C512 当新档。
- 不把同名义 Q 当同成本；不把 CPU 信号当 GPU 证据。
- 不在机制通过前调路径/阈值；不伪造不支持的语义（snapshot、2B 单块、C512）。
- 不动集群/Git；本文只是设计。

## 10. 一页纸结论

1. **尾部：** 不做默认竞争者。LLaDA Q64 / Gemma Q512 做“头块选位冻结 + 余量只建尾块 KV + 当轮不采样”的最小实验；用同 Q 头块重读对照隔离信息价值；尾块采样单独作为投机臂，并测降档债务。先验是尾块 KV 会被提交/重编码作废；若 KV 有效率/交付率 <50%、撤销 >20%、同 Q 无增益，淘汰。
2. **2B：** 2B 是容量档，不是 B 的别名。联合块因果前向必须在同 Q 下赢顺序 2×B，在质量/TPF 上非支配单块 B；active-only 是唯一明确的成本收益；FlowBlock W2 只作外部参照。若不赢，2B 不作默认。
3. **刷新:MASK：** 先测逐轮分布，再试 β=0.5 的刷新上限（欠账结转）。低档刷新占比高、纯排水多；若封顶不减少纯排水或不同 Q 改善质量/TPF，淘汰。比例只有通过“同快照升/降档边际价值”检验后才作切档信号。
4. **任意切档：** 先做状态合同、转移矩阵、同快照分支；同名义报价不等于同物理工作；升/降档对照必须在同一状态快照上分支。路径探索最后做，且只在三个机制至少一个通过后进行。
5. **阶段门：** Phase 0 → 尾部 → 2B → 刷新 → 路径；未通过就报负结果，固定档 K0/IBS 仍是默认。不用路径搜索救失败机制。
