# 单请求设计赛马：头块优先、尾块借余量、2B 单独验收

**首选：先把硬限额单块做成可独立起步的基线，再验跨块。不复活 `00/10/11`，不把填满 Q 当作目标。** LLaDA2.1 先在 Q16 验证有上限的块末复核；DiffusionGemma 先在 Q128 验证把必刷并进完整的终检，`K=0`。跨块候选保持头块选位不变，只把同一次 forward 的真实余量借给下一块。`q=2B` 提供独立的 FlowBlock 式因果双块路径；有档位不等于必须提前开尾，也不等于和 W2 采样等价。下文为设计和准入条件，没有新跑分。

## 2. 一套硬预算契约，两种模型生命周期

**记号。** `q` 是外部给下一次生成 decoder forward 的实际行硬上限；`D` 是仍存活的头/尾必刷绝对位置；`M` 是头块可合法推进的未解位置（LLaDA 的 MASK；Gemma 的未接受位置，不是字面 MASK token）；`P` 是当前头块内、首个未解行之前、已初始化且干净的连续前缀候选。不把 prompt 或已提交块算进 `P`。冷位、欠验证位、已解复核位各单独标记。物理投影用并集，不能把一条既脏又未解的行计两次。纯 prompt prefill 单列；LLaDA 的生成期 bootstrap/verify/commit 都受 `q`，Gemma 生成期 encoder 单列计费、不占 decoder `q`。

**因果与驻留。** 同块保留原生合法双向边，后块可读头块，头块不得读未来块的 K/V，即使后块本轮 Q=0、只刷新、已停车或和头块一起投影。块编号用模型实际边界：LLaDA 按 B32 的绝对网格处理 prompt 尾部；Gemma 按 `(pos-origin)//256`，保留各层原生前缀与滑窗限制。复用 [LLaDA 真实 gather/scatter](../../../../bdlm_serving/methods/t2t/llada_budget_request.py#L45)、[Gemma WaveKV](../gemma_wave_kv.py#L333)，不按当前 Q 列表重编号，不发布 KV 空洞或失效版本。LLaDA `_Bank` 要求新增位置连续；不能为稀疏尾块先跳过头块未建行。Gemma 的 SC 有效位和已接受标记分别维护，不能用占位 logits 伪造冷启动。

| 情况 | 执行优先级 |
|---|---|
| `len(D) >= q`，或头块处于重建屏障 | 每次按确定序做至多 `q` 行实际刷新/重建；欠账带到下轮。首版保守地不消费 drain 的 logits，不推进 RNG、denoise 年龄或终检计数。不让新采样依赖未刷的旧输入。`len(D)==q` 也明确纯刷；已有 dense 路径的「满债但采样」另验，不悄悄混入。 |
| `len(D) < q`，头块可推进 | 必刷全放进去；同次 forward 按不跨块的头部基准顺序加入合法的 cold/MASK；必刷行若按当前 sampler 合法，也可在**同一行**取新 logits。不能为了补前缀而少算本可推进的 MASK。冷/暖联合投影不代表两组可混采；保持各模型原有适配器的消费约束。 |
| 头块进入收尾 | 用该档付费覆盖应有的复核/终检行，当前版本和覆盖要求满足后才提交；默认收尾不新开尾。允许同一行刷新兼终检是独立实验；分片收尾不冒充原生满块验证。 |
| 头块正常推进后确有空位 | 顺序为已登记的头块附加工作（若有）→ 通过准入的尾块 cold/MASK → 留空。默认头块额外 `P=0`；前缀试验开启时，其上限和尾块试验分开钉死。尾块先只处理未解，不补尾前缀、不强行填满、不额外起一个 forward。 |

**前缀刷新 : MASK 的可执行定义。** `D` 无比例、不得舍弃；另记 `P : M`，分开记录 `M` 与 `D` 的重合。首选饱和轮额外前缀为 0；富余轮选完全部基准头部工作后，LLaDA Q16 可登记右缘最多 `min(slack,2,|P|)`（Q8 仅复验最多 2，不外推到 Q4），Gemma Q128 保持 0，另验最多 `min(slack,32,|P|)`。不把 `q/8` 分给每个块，也不为了达到比例而牺牲 MASK。先用 `KV-only` 只刷新；`editable` 才允许其进入 sampler，且用相同位置作首干预配对。LLaDA 的无 MASK 块末复核是单独的已解位置集合，不套用这里的前缀比例；Gemma 的终检也不是可选前缀。若以后要验挤占，把 `floor((q-|D|)/8)` 比例交换作为单独劣势对照，只在仍至少保留一个可推进位置时发生；不能与尾块准入同改。

**尾部准入与 2B。** 稀疏档首个登记门槛：头 KV 已完整驻留，头可合法采样，头未解不超过有效头宽的 1/4，无头 EOS 候选、未到输出上限，且基准头计划确实留了席；只允许一个相邻尾块。首次选尾后继续受每轮余量约束，头因撤销变忙可停车。门槛是可证伪假说。`2B` 的候选先算满**有效头宽**，门槛允许且尾能推进才纳入有效尾宽，用一次因果 forward；提前开、晚开、不开分别注册。无合法/可推进尾块时不算幽灵 B 行；已有尾欠账仍记。两块从同一 forward 的旧快照取 logits，不能让尾读到同轮采样刚写出的头 token；这些写入进下轮债表。W2 是独立的固定预算对手，不是一个 mask 开关。LLaDA 预算 B32/2B64；Gemma B256/2B512。短尾、半个 prompt 块按模型的合法物理宽度计，Gemma 若适配器要求满 canvas 才能终检，必须真计满 canvas 的行、只交付合法长度，不能把模型需要的行伪称为 padding 免费。

## 3. 任意切档及不能省的操作

- **同一请求跨档，不换 sampler。** 外部逐 decoder 调用给档，任何已支持档可冷起或接在任一档之后；不内置周期、启程大档或下一轮自动升档。正式五档为 LLaDA `4/8/16/32/64`、Gemma `32/64/128/256/512`；若接收档间整数，先按同一不变量单独验覆盖和进度，未验范围显式拒绝，不能向上取整或把不可行小档当合法完成。`q=B` native 和 `q=2B` W2 是独立对照，不是混合请求中替换 sampler/stopper 的指令。尤其 Gemma 的 [SelectedRowSampler](../gemma_strict_sampler.py#L1) 是 measured-row 近似，原生需要整 canvas 熵排序、随机序列和 stop，升档也不能从半块凭空恢复原生状态。
- **大→小：冻结尾的可选工作，不冻结账。** 持久化绝对行、有效位、版本、未解/接受/SC、待刷原因、每块 RNG/采样年龄、验证 cursor 和 EOS 候选。新档下尾债仍 b0/b1 共用一个 `q`；全量旧债若放不下就分轮还，不丢弃、不透支、不采样。例：`2B→q` 时头欠 `q-2`、尾欠 5，首轮刷头 `q-2` 加尾 2，余尾 3；下轮若头仍可推进，先刷剩余 3，再以新档余额选头。尾被停车时不移动其采样时钟；它的同 epoch 驻留 K/V 仍须接受因果屏蔽。历史 [LLaDA 32↔64](../llada_top_transition.py#L109) 与 [Gemma 五档](../gemma_unified.py#L186) 能证明路由/开销可观测，曾允许必刷超名义 offer，不是这里的硬限等价实现。
- **小→大：复用已证实有效的状态。** 不重跑 prompt、不重置块龄、不丢部分终检或新写入；未建位置按实际行补齐。同档重复也走同一事务。升档到 `2B` 若仍在 drain/rebuild/verify，按该阶段扩大本轮切片，不能跳过屏障直接开始采样；降档不降级结束条件。Gemma 若 48 步到限而覆盖未全，按既定适配器判失败计错，不把未完成随机 canvas 发布。
- **提交头→晋升尾。** 只按块顺序交付；有效区内 EOS/长度截止优先，丢掉其后的投机输出、KV 和债并记录失效原因与已经花的 Q，不伪装成已推进或已还债。非终止时，LLaDA 必须有合法提交的逐层 KV；若头上下文版本/KV 因提交发生变化，尾旧 KV、`done` 和无 MASK 的稳定性凭证失效，按新头前缀重建并重新验证，不能直接双提交。[旧 `llada_dual`](../../../../bdlm_serving/methods/t2t/llada_dual.py#L398) 有独立 commit/reencode；新 `00` 的零债退休并不证明它们可删。Gemma 用终检产出的 draft 而非临时 ids 提交，非终止时付费 encoder 写入整个被提交块；[现有晋升路径](../gemma_fixed_dual.py#L51) 只带尾画布/采样态，不跨 encoder epoch 复用 decoder KV。保留候选 ids/RNG/SC 是投机初值而非有效性证明；在新 epoch 分片重建，按登记语义重做必须的终检/复核，禁止继承旧 `done`。保留 SC 与清 SC 重启是两种策略，若要比较另外登记。
- **不能省的是一致性和判定，不一定是独立 forward。** M2T、严格 T2T、撤销、Gemma 重加噪等已承诺需进入 KV 的输入变化须清偿；同样跟踪所采用 SC 协议的输入版本，SC-only 触发强制重投影若新增，须单独验成本，现有 `StrictRows.finish` 不等同于该策略。只有从当前输入、合法版本的实测 logits 取样，且每块每次只消费一次。LLaDA 只有满块、零改写、同输入/位置/前缀版本且逐层 KV 可发布的验证才可候选复用 commit；严格小档凑齐分片不构成满块等价凭证。Gemma 可合并必要刷新与本来就要做的终检，但必须完整覆盖、使用正确版 KV 且不跳 encoder。投影或写入半失败则失败关闭，不能在部分写过的 bank 上重放。

## 4. 独立消融和淘汰

先冻结 checkpoint/实现摘要/硬件、frozen 原 30、种子、prompt、最大长度、评分与失败记法。每条为独立完整请求；各臂除登记变量外保持相同 sampler、EOS、物理 cap 与初始 RNG/块映射。冻结决策状态做局部回放，核对首干预前输出、位置、RNG 与 KV/version；首干预以后允许轨迹分叉，不用事后对齐来删掉成本或丢题。

| 次序 | 只切换一件事 | 判别点 |
|---|---|---|
| A：单块起跑 | 先复现硬限 IBS/OBS，B 档另复现 native/W1。LLaDA Q16：同一个硬限单块母体对「无额外复核」vs「无 MASK 且头债清零后，一次至多 4 个已解头块位置的复核」；固定最近已解位置的排序和编辑阈值，改写/回 MASK 则纳入债与正常推进，每块至多触发一次，不替换母体的必要收尾。Gemma Q128：`K=0`，同一母体的先刷再终检 vs 债优先纳入原终检，终检集合和逻辑提交相同；另外才测 warm 轮消费已经算出且合法的 logits。 | LLaDA 记录复核是否改写、后续刷债与配对救/丢；Gemma 按债量和收尾阶段统计少几次 forward，同时检查顺序差引起的任何输出变化。Gemma 已有三题信号优先复验，两个干预不叠加。 |
| B：前缀 | 单块、同一收尾：`K0` vs 只用余量的 `KvOnly(K)`；再用同首轮行集合比较 `KvOnly(K)` vs `Editable(K)`。如需更强归因，再验等宽替换已解非必刷位；挤 MASK 的配额只作独立臂。 | 对账头 MASK 席位不减、实际注入和改写；KV-only 的后续分叉可能来自上下文，不是直接编辑。零触发的臂没有估出效果。 |
| C：尾部 | 固定 A 的胜出单块母体、关闭 B，先比较尾关 vs `slack-only`（同头计划，选中尾行当场合法采样）；再在相同开块和首投影位置下比较「只建 KV」vs「建并采样」。整块预建另做：只有 `B` 行真能塞进当轮余量时比较，不能在 `q<B` 整建，也不把分轮建和一次整建称等价。 | 成对报实际开/关暴露、首次头计划一致、尾首建/保留/撤销/重建/Q、尾债侵蚀后续头席，以及是否真的少了后续 forward。`slack-only` 只保证当轮不抢头，并不保证跨轮无成本。 |
| D：2B | 同一个因果执行器固定 `2B`，尾禁开 / 晚开 / 早开，一次比较一个预注册对照；独立比较真实 FlowBlock W2，另列 B 档 native/W1 的实际费用。若要验方向，只放开头 Q→尾 K 边，其它几何/缓存/布局/阈值不改；对「尾只有驻留 K/V、没有 Q」也做首干预见证。 | 不复用 `00/10/11` 的同顶档当重复；未暴露题保留在全样本。逐层掩码检查与固定输入/扰动的 MoE 数值差诊断分表，后者不算任务生成成本。 |
| E：切换 | A–D 固定档获准后，比较同一外部 trace 的严格单块参考和有尾候选，并分别对固定端点；先作结构审计，再做质量。覆盖全档冷起、同档恒等、任意两档有向切换、反复大小切、长低驻留、verify/rebuild 中换档、尾债大于 q、低档提交晋升、EOS 作废、半头/短尾。 | 同一 offer 序列不保证同实际成本；记实际消费时钟、首下切的 drain 次数和恢复长度。诊断可以用构造状态；不把构造/短测当质量分，也不因 trace 每题触发次数不同筛题。 |

**门槛（提议，跑前冻结）。**

1. **硬淘汰**：任一非 prefill 的 decoder 实投影超 `q`、重复/虚构 Q、未初始化或错 epoch 的 K/V 被用、可见性方向错误、必刷丢失（显式终止作废除外）、非法采样/时钟、尾越序提交、漏 encoder/verify 计费，均整臂失格。逐层核真实 Q/K/V 投影和写入，不能只信计划；同档→同档应逐位重现母体（在确定性配置下），所有未触发路径应重现。真正影响精度的布局差单列，不把数值不等直接定性为 attention 泄漏。
2. **30 题筛选，不宣告胜出**：对同协议母体，正确数与宏 TPF 点值均不得下降，且至少多对 1 题或 TPF 相对提高 ≥2%；`ΣQ_physical` 与 P95 请求 GPU 时间若任一增加 >5%，不进下一轮。对预注册的同档外部强对照（LLaDA Q16 同报硬 IBS/OBS，Gemma Q128 主对 OBS、同报 IBS；2B 主对 W2），若某个对手的正确数与 TPF 均不低于候选、且至少一项更好，候选淘汰，不作默认。纯机制诊断可以报告差异，但不晋级。「掉质量换 TPF」只记取舍。没足够暴露先判未识别，不扫门槛捞赢家。
3. **新增 60 题复验**：原 30、新 60、全 90 和数据集分层同时报告；要求全 90 仍满足点值准入，新增 60 不反向，不以试后重调阈值替代确认。正确率差与宏 TPF 差用逐题配对区间（正确率另报救/丢）；建议全 90 的 95% 下界守住预先冻结的非劣幅度（质量 −3 pp、TPF 相对 −2%），并至少一项的提升区间排除 0，才称可推广。过不了就保持参考路径；区间太宽叫不确定，不叫等价。阶段、档位各自验收，不拿别的档的胜利补亏。
4. **完整计费**：`macro TPF=mean(N_i/F_i)`，`physical efficiency=ΣN/ΣQ_physical`；N 是最终交付，T2T 不加 N；F/Q 含生成期所有阶段（含 Gemma encoder），另列 decoder F/Q、每次 Q/上限、峰值和分位、总 N、阶段数、失败/截断和同设备实测 ms/token/P95。区分尾部前跑中最终保留的进展、被撤销/废弃的已算行、晋升后重建的行；可另列历史前缀 Q 指标，但不拿它替代物理 Q。原版名义窗口、硬限适配器、早期配对及不同 cohort 不混为同成本。
