# 单请求：预算不足时保什么，预算充足时多算什么

登记日期：2026-11-28。状态：设计及固定预算筛选中。下列顺序是执行契约；开块阈值和前缀比例是待验证参数，不是胜出的配置。研究对象仅 LLaDA 2.1（B32，C=4/8/16/32/64）和 DiffusionGemma（B256，C=32/64/128/256/512）。这里不设计多请求排布。

## 每个 forward 的判断

1. 外层只给当前的 `C`，没有未来预算或答案。请求保存绝对位置、物理块 ID、token/接受状态、每块内的连续前缀、dirty/初始化位图、上下文版本、采样器状态和终检游标；预算不是缓存键。块内双向、前块 Q 不见后块 KV、后块 Q 可见合法的前块 KV。未建和失效 KV 不可当作有效 KV。
2. **不能省的是一致性，不是所有已解位置都要重算。** 上轮 M2T、T2T 或撤销导致 token/接受状态变化，进入必刷集合；在当前方案中，若 Gemma 所用采样路径还改变了输入 token（含 re-noise），也按其契约记录。合法复用的是相同上下文中没有失效的缓存。干净前缀复看与必刷单列。终止/EOS、LLaDA 的所选对照执行器要求的 commit、Gemma 的终检/非终止块 encoder 提交都不能静默略掉；不同执行器有不同结束语义，不能把旧消融的退休规则冒充原生 commit。
3. **钱紧时**：先还必刷和到期屏障；`dirty>=C` 且无法完整一致地采样时，分轮只刷新，不推进采样时钟。若尚有余额且有头块未解 MASK，优先保证头块能获得至少一个真实可采样的位置；需要首次建立上下文的行优先于可选复看。仅在上下文有效、该行本轮确有可用输出、模型规则允许时，刷新可与采样共用同一次 forward。不会为了维持固定比例而搁置必刷行。
4. **常规预算**：在扣除硬性工作和首次建行后，以 `0、1/8、1/4、1/2` 作为干净块内前缀可选份额的候选，余下给 MASK；无可选前缀就回流给 MASK，有真实余量才考虑后块。前缀从各物理块独立确定，不读未选行 logits。验证时分别统计必刷、首次建行、MASK、干净前缀、验证和重建；不能仅用配置比例代替实际比例。
5. **2B**：最多同时推进两个相邻物理块，头块全量有保证；后块只有在无前块 EOS、未超长度上限、且满足开块条件时进入同一次块间因果 forward。不开、立即、头块有效行已完整且余 MASK ≤B/2 或 ≤B/4 是同实现的四个对照。若终止风险大、后块不可用或已无合法采样工作，预算是上限而不是填充目标。B 中产生的位置更新可按位置带版本对外报告，但不能冒充不可撤销的最终 token；头块提前 EOS 撤回越界后块。Gemma 后块晋升时 encoder epoch 变化，旧 decoder KV 不跨 epoch 免费复用。
6. **小档跨块只借余额**：锁定同一头块计划（含其可选前缀配额），开启后块只用该轮剩余位置；对照同采样器的头块单独运行，先固定 `1/4` 门槛，后单独改 `1/8、1/2`。后块的写入会带来后续必刷债务，故只能承诺“不挤掉本轮既有头块名额”，不承诺未来无影响。若余量几乎为零，此规则是无操作，不能报作提速。

## 任意切档，不等于已经找到好的混合路径

`step(C)` 的输入只约束本轮。平档、跨档、升档、降档共用同一个请求；不重做 prefill，不重置随机数、采样时钟或已经有效的 KV。升档先消费积压，再买新 MASK/可选复看或后块工作，不强制从原生大档开始。降档先还全请求应刷债务，后块可停放，新预算只能限制本轮消费、不能抹去已发生的写入。正在进行的终检/重建保留游标，按本轮额度分片；确有语义要求的整块 encoder 另计 F 和行数，不能改名隐藏。上下文版本变更与预算变更是两件事。新实验的 decoder 上限是硬上限；旧实验 `build_sample` 或 native-close 的整块例外不能混入。对历史 attention-budget 实验，也不得把物理全块 Q 写成这里的物理稀疏 Q。

先验证每个档可独立起步；再做 5×5 有向切档合约测试，覆盖有 dirty、后块已开、终检进行中、encoder 晋升、EOS 和预算连续振荡。恒定预算输入必须复现相同执行器。此处验证正确性，不做混合路径排名。

## 因果对照、指标和下一步

| 单因素 | 固定项 | 主要反证 |
|---|---|---|
| 2B 后块开块时机 | 同一采样/终检、头块覆盖、因果掩码与最大 C | 第二块虽算满，没有减少 F；后块最终匹配少、作废或重建吞掉收益 |
| 小档借位 | 同一头块计划、比例与开块阈值，关/开借位 | 借位罕见，或其后还债导致配对 TPF、质量退化 |
| 可选前缀份额 | 仅单块，同预算、cold 策略、排序、阈值 | 编辑虽增加但质量没有救回，或 MASK 吞吐与 TPF 下滑 |

全部固定 frozen90/seed/输出上限/评分；同时报原30、增60和全90；新增60在过去研究中已用，不能称为独立未见测试集。原30可筛掉差方案；后60用于验证方向，不逐题调参。与同预算原版 Optimus IBS（注明实际 Q）、原生解码与相应 FLowBlock W1/W2 对照；硬预算主张要再匹配实际用量。宏 TPF=`mean_i(N_i/F_i)`，含生成阶段实际 post-prefill decoder 和 encoder；token efficiency=`Σ最终非特殊输出N/Σ实际读取历史KV的选中decoder Q`，同一 token 的 T2T 不多计，物理投影、边数、encoder 行和额外工作另报。记录救回/丢题、失败、截断、实际 Q 与前后块最终保留的去重 token。token 相等仅是保留证据，不等于因果贡献；是否节省 forward 必须用配对对照。筛选原则：质量与 TPF 都不退、至少一项有正信号；一两道题的波动标为不确定，必要时给按题分层配对区间。无效就不叠加，存在权衡就如实报告。

**最后才研究路径**：锁定固定预算方案与切档正确性后，以恒定预算、同预算组合的高→低、低→高、周期交错及只用在线状态的切换为候选。比较相同真实选 Q 工作量区间，并报告因提前停止导致的预算、F、Q差；不能用名义算术平均冒充等成本。先分开“请求尾部”和“每个物理块尾部”。起始可用任何档，外层可随时覆盖；推荐策略不构成请求的启动前提。路径的状态响应可从同一冻结的切换前状态分叉单步测量，不能用静态各档 TPF 直接拼接推断。

## 已落地的首个检查点

Gemma 的同执行器新增 `top_gate`（off / eager / half / quarter）和可选 `head_first`，不开、立即开、晚开不改变头块的全量行，也不改变采样器。`cross_race.py` 记录每次请求的真实 decoder/encoder F、Q、尾块去重位置、最后一次后块预测与最终 token 的匹配数、作废成本。统计 `tail_final_matches` 不含 EOS 等特殊 token，也不是被加速的因果归因。计划器测试含全部 25 组有向切换；49 个计划器测试在锁定的 Gemma 依赖中通过，不是动态路径的推理成绩。

首个 smoke：同一冻结第 0 题、种子、A800、C512。四种解均正确；不开后块：N=395、F=24、decoder Q=5,392；立即开：N=402、F=17、Q=5,710，后块产生的候选中 137 个位置最终匹配；半块与四分之一：均 N=391、F=25、Q=7,206，117 个最终匹配。**这不是总体结论**；有终止风险的短题与多块长题都要保留在分母中。完整样本在集群，不在仓库提交模型输出。

## 三份独立提案及取舍

| 评审 | 最值得保留的分歧或试验 | 本轮决定 |
|---|---|---|
| [GLM‑5.4](cross_block_glm54.md) | 将后块「只建 KV」和「建并采样」拆开；用相同状态做升降档分支，不把静态曲线拼成路径。另提议紧预算保 MASK 最低份额。 | 接受将尾部采样权限单列。不给 MASK 强占真正的必刷席位；若要延期刷新，先证明被延期的行不会被当作有效 KV 读取。 |
| [DeepSeek‑Flash](cross_block_deepseek.md) | 头块优先、不让投机挤占头块；区分物理 B32 与 B256 全投影的负担。其保守路线是只给后块建 KV，选行读历史与投影前选行分开。 | 保留作为对照，不照搬“2B 已被否决”或“块内全投影一定不能省”的判断。此前测的是特定执行器；同样保持双向可见性不等于每轮必须投影全部行。 |
| [GPT‑6.2‑Sol](cross_block_sol62.md) | LLaDA 的块末复核、Gemma 的必刷与终检能否合并，可能比单调提高前缀比例更有效；跨块的未来欠账须单列。 | 把收尾合并留为独立实验，不与当前开块门槛一起变化。若终检消费的是不同输入、不同采样态或不同 epoch 的 logits，禁止合并。 |

上述文档是未经统一裁定的原始提案，其中个别阈值、固定档先验、跨实验指标和“不能省”的判断不作为执行合同。主合同是本页。下一步只在相同开块时机、相同选位上切换尾部采样权限；按块版本化的即时更新、前方 EOS 回撤和最终有效输出分开计。仅当同题同种子固定预算的质量与宏 TPF 均获支持，才把新增特性并入默认策略并开始混合预算路径排名。

立即开比本执行器不开多用约 50.6% decoder Q，TPF 提高约 9.4%；四分之一开每多用约 4.8% Q，宏 TPF 只提高约 0.7%。这支持「顶档能真的在第二块做事」，不支持「顶档应该每轮无条件算满」。原 30 上四个新执行方式的 TPF 都低于三个外部参照。单题净胜无法确立质量优势。复算见 [配对汇总器](../cross_race_report.py)；来源见 [外部基线表](../controls/block-history90-matrix.csv)。

LLaDA 2.1 的 H800 新实验在 Q64 同样登记四种开块策略。LLaDA 这一臂是在两块候选上用原稀疏选择器选行，不等于 Gemma 每次 denoise 都对两个可用块做全行投影；因此不能实测背书「两程序都是物理 2B 全算」。Q8/Q16 的借位控制是「头计划不动，后块只建 KV、不采样」，与 Gemma 小档的「允许后块采样」也是不同干预。只能先在各模型内部跟自己的不借位组做因果对照。未凑齐同题组前不报告该模型整体收益。

## Gemma 单块：前缀复看占可分配行的份额

原 30 同题同种子、禁止开后块。在本消融中，`0` 意味着不给**干净前缀**额外复看机会，不是关闭上轮写入的必刷，也不是移除所有前缀 KV。各格为 **正确/30，宏 TPF，token efficiency**。

| 固定预算 | 0 | 1/8 | 1/4 | 1/2 | 外部原版 IBS |
|---|---|---|---|---|---|
| Q64 | 27，6.597，10.63% | 29，7.713，13.07% | 29，7.767，13.00% | 29，7.297，12.00% | 29，11.007，17.24% |
| Q128 | 28，10.304，9.81% | 30，12.024，11.25% | 30，12.034，11.20% | 29，11.737，10.52% | 25，16.471，14.28% |

初筛保留 1/8 与 1/4；两者 TPF 差很小，不以小数点后的差异挑出冠军。配置比例不是实际比例：例如 Q64、1/4 合计采买 3,809 个干净前缀行，同组有 37,365 个必刷行和 25,273 个未解行（另有验证等类别）。同样 Q128、1/4 分别是 4,436、44,467、24,246。此处「未解」未进一步区分首次建行，三个数字不能冒充全部物理行。两档均未追上归档 IBS 的 TPF；Q128 有质量与效率的取舍。待增 60 与全 90 验证。
