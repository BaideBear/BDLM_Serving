# LLaDA sampling endpoints (CPU evidence; GPU proposal only)

**Verdict.** A common projection/result interface is possible; physical `q` is a cap, not sufficient information for a common accept rule or a bit-identical model forward. A projection plan needs actual absolute rows, positions visible to each query, and sampled rows grouped by physical B32 slot. A result carries only current measured logits and prior token/prompt masks. Strict IBS chooses its upstream subset (including debt) inside one block. Compact W2 projects `32 * opened` rows (32 or 64), including opened but locally finished slots; only active unfinished, non-exhausted slots can transfer. At budget 64 a compact single-slot tick is physically 32, so a width test cannot even distinguish that call from full-block IBS. This interface does not unify retirement, cache layout, or numerical execution.

**First operational incompatibility.** Hold projected logits fixed. IBS uses argmax and sparse measured MASK scores, `>= .9`. With any measured MASK it sets the single block `topk(1)` score to the threshold before thresholding; unmeasured rows have zero-filled scores. No measured MASK means no forced write. T2T evaluates the measured nonprompt non-MASK rows whose argmax differs with FP32 confidence `> .5`, even on a no-MASK call. See `bdlm_serving/methods/optimus/fixed.py:39,90,153` and the actual upstream `unmasking.py:68,106,124` (SHA `bbc3c3328e5497aa08aed6e04150ab0383f95dc06b4ff570a69adaed4a769746`). Flow uses temperature-zero top1, strict `> .5` M2T and strict `> .5` changed nonprompt T2T. It forces one `argmax` over that slot's measured MASKs only when none pass; no fallback on an empty MASK group. Two simultaneous slots do not share one winner; masked and edit transfers can occur together. Post-edit budget is 16. Its spawn statistic uses `>= .5`, **not** the M2T `>` comparator, and gate `.8` is not an admission cutoff. The two tie-breaking implementations (`topk` vs first `argmax`) are not interchangeable without a tie qualification. Sources: `tools/llada_flow_active_w2_study.py:48`, `bdlm_serving/methods/flowblock/llada_active_w2.py:106`, `flowblock-frozen90-1127/third_party/FlowBlock/dInfer/python/dinfer/decoding/flowblock_packed.py:80,126,309`.

In the proposed treatment below only the head's forced M2T disappears; actual T2T and all 32 tail admissions are untouched at that fork.

**Single GPU factor proposed, not implemented.** On frozen compact W2 only, keep the same per-slot best MASK, but suppress its fallback if that *same slot in this forward* already has a real nonprompt T2T change to a non-MASK token. No veto on threshold-passing M2T; another slot's edit never qualifies. Existing T2T ensures a transfer, so suppressing the fallback cannot falsely set `newly_finished` at the fork. Freeze thresholds, width, selected rows, native proposal/RNG, post counter, spawn signal, commit, KV, stopping and billing; leave all later trajectory changes to the native controller. No extra forward. Distinct from Q8 cold-vs-waiting fallback *ranking* (`llada_window_fallback.py:20`), partial-cold-start no-fallback with no T2T candidates (`llada_low_start.py:63`), relaxed M2T (`llada-admission`), or turning off no-MASK paid edits (`llada-ibs4-no-mask-write`). Found no registered equivalent in this checkout.

Conservative observed exposure: 282/5,558 compact ticks, 59/90 requests (19/30 original and 40/60 new; 223 single-slot, 59 two-slot ticks). `frontier=0` certifies no MASK even reached `>=.5`; require one actual M2T plus an actual nonprompt non-MASK→different-non-MASK edit in that slot. This lower bound avoids misclassifying equality at `.5` as a natural admission; it is not a rollout gain. Proposed gate: old fixed six `7,13,25,33,55,71`, no outcome substitution. Bare vs instrumented no-op identical on the same board on six; at least one predicted first fork, equality of all pre-fork rows/logits, decisions and F/Q; at fork only one forced M2T per eligible slot removed, with same native T2T, physical bill, slot status, and .8 spawn signal. Otherwise stop. Report paired origins/new60, correct gains/losses, EOS/failures, N/F/Q, macro TPF and pooled TE; more forwards or lower quality are possible. Not a full90 experiment authorization.
