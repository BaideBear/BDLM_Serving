# 当前物理块内：固定前缀刷新数量，只换位置

本轮把两个问题分开：是否该用一个前缀 Q 替换一个 MASK Q，和已经分给前缀的 `k` 个 Q 应该放在哪里。只有后者使用本目录的算法。

## 相同名额，连续选择还是分散选择

保持父算法本步选出的 MASK、必付写回、前缀名额 `k`、物理块、注意力可见范围以及采样逻辑。对当前物理块，列出全部合法的、已付清的生成前缀候选 `x`（升序，长度 `n`）。对照取最后 `k` 个位置；处理组将候选列表按排名分成 `k` 段，每段取最后一行，即 `x[ceil(j*n/k)-1]`，`j=1..k`。`k=0` 两者都不选；`k=1` 两者都选最右一行。输入可以是不连续的合法位置，不能把两候选之间的空洞当成可选行。单步不增加计算数；后续实际 N、F、Q 可随轨迹变化。

这条规则不用 logits，不预测 T2T，不增加 Q 预算。两模型用[同一函数](../../../../../bdlm_serving/methods/t2t/prefix_coverage.py)，SHA-256 `d9bba93815a4b015f4ec5405c0542ca3e4c969484f63f813faec3b1668c43006`。LLaDA Q8/Q16 参照使用 IBS 剩余槽位，附加行只刷新 KV、不采样。Gemma 的对照是支持 T2T 的 Live，维持原有前缀名额和原生采样权限。父算法不同，结论只作各自同卡配对。

这是对**同一次真实 forward 之前的可用信息**重算选择。右端对照实际投影了 5,437 个前缀 Q、共 18,753 次生成 forward；分散策略并未在这些历史 90 题上解码。2,486 是会替换的行次，不是已省的 Q/F，更不能推出质量。此轨迹的停止规则也不同于新六题的付费 EOS。原冻结题和 180 份原始双臂回执哈希核对通过。[紧凑结果](llada-q8-exposure90.json) · [复核程序](../../../../../tools/prefix_coverage_exposure.py)。

六题固定为 `7,13,25,33,55,71`；没有换题或剔除长尾。先要求不改变行为的对照复现原生轨迹，并确认第一次处理分歧只变相同数目的前缀行。新候选进入 90 题的门槛是：有真实选位变化并通过物理验证；同卡六题正确数和宏 TPF 相对父算法都不下降，至少一项提高，且不能同时增加总 F 和总 Q。六题仍是开发集，不作正式结论；已有或进行中的其他因素不合并。

## 另外两项独立结果

- **牺牲一个暖 MASK 来刷新前缀：** [Gemma Q64 六题实跑](../prefix-clamp/gemma-q64-physical-seat-six.json)及[同方向的 LLaDA Q16 对照](../prefix-clamp/fixed-budget-checkpoint.md)。这两组改变了 MASK 数量，不是分散选位实验。
- **Gemma `2B` 的开块信号：** [六题更正](gemma-q512-causal-gate-six.json)。原 eager 回放用本轮选 Q 之后才得到的 EOS 采样结果来推测本轮可省 `1,280 Q`，这一收益撤回。真正的半块阈值开块路径上，四题未开后块；另两题在 tick 5、8 首次打开，上一步均没有被原生采样器拒绝的 EOS 提案。此信号在这六题有 **零次可执行的延迟机会**，没有处理组成绩。原始 `gate-ticket.json` 留在 n164 的 `results/gemma-q512-gate-ticket-20261128T224118/`，SHA-256 `7898552e4dff300428b7bb10702d1760ca2c6de1b7b7d5e082995634cb807a3a`。
- **LLaDA `2B` 首次只建立半个后块：** [H0 的六题配对](llada-q64-first-tail-six.json)。Q64、原开块阈值 0.8、头块全 32 行不变；后块首次只计算、采样前 16 行，禁止读取尚无 KV 的列。如后块继续存活，下一轮实算全宽。六题首次双块投影均为 64→48 Q，头块当轮写入无差异。共 44 次只建半块，40 次后续补齐，4 次在终止时未读后半块。整条请求 6/6→6/6，TPF 11.937→9.745，TE 21.94%→21.73%，总 F 121→144，总 Q 5,952→6,048。比起只看首轮省掉的 16 Q，整条请求的代价支持保留完整首次投影。不扩 90。n164 原始目录 `results/llada-flow-successor-first16-h0-six-v2`，独立审计通过；不要混入没有有效回执的 v1。
