# LLaDA 2.1：旧位是否值得替换当前席位

开始评测前冻结以下规则；这是反复使用 frozen30 后提出的假设，不是独立盲测。校准仅用原有外部于 frozen30 的同来源 24 题，检查 `source_index` 和题面摘要无重叠。只训练两个小查找表：旧位在下一轮被严格改写的概率，以及一个 MASK 在下一轮被写为非 MASK 的概率。训练标签来自原生去噪；旧位和 MASK 的事件不等价于最终质量。Gemma 原生非 fresh 严格改写分母为零，因此本表只用于 LLaDA。

选择器不读 token ID 或 logits，只看位置、MASK、上一轮写入/改写集合以及写入时间。旧位按最近 fresh、MASK、上轮改写和自身写入年龄分桶；MASK 按其在未解码序列中的顺序、最近 fresh 及剩余 MASK 数分桶。桶按所属池总体概率做 16 个伪观测的收缩；空桶回退到该池均值。

从同状态零预留的物理 Q 集合起步。全部 fresh 必刷不截断；如有剩余，首个 MASK 不可换。候选只取**本来不计算**的已解码旧位。若原选择里有普通旧回填席位，只在候选风险高于被替换旧位时换入，不再挤 MASK。否则与最后一个本来入选的非受保护 MASK 比较，候选的估计改写概率乘预设价值系数，高于该 MASK 的估计解码概率才换。没有换就按原选择算，实际 Q 数不变。每轮在当前状态重算决策，不使用原生路径透视。工作量在后续轨迹上可以改变。

预定等价值与编辑值四倍两个条件；Q4/8/16 的最大换入数分别为 1/1/2。两种条件都报告，不根据质量选系数。B32/Q32 已全选、单块 Q64 饱和，均没有可换候选。先看原生同状态候选与被换位置的事件交叉计数，再按同一 30 题真实稀疏执行，与同 Q 零预留比较质量、TPF、物理 Q、token efficiency。每个设备组先复现 30/30 全宽路径。完整生成费用含初始化、选位、验证和提交；单列 prompt prefill，不计入生成。
