# 写回干预前的轨迹核查

在同预算零预留与编辑四倍策略间配对固定的 30 题。下表按**四倍策略的实际轨迹**是否在新增换入行当轮发生过严格非 MASK 改写分组；表内赢/输是最终判分，不能用于直接推出屏蔽写回的因果效应。

|Q|换入行曾直接改写|题数|仅四倍正确 / 仅零预留正确|配对宏 ΔTPF|
|---:|---|---:|---:|---:|
|4|否|22|1 / 0|+0.0877|
|4|是|8|0 / 0|+0.0834|
|8|否|21|0 / 2|−0.1010|
|8|是|9|0 / 2|−0.1835|

Q4 总计 343 次实际换入、9 次严格命中；唯一由错转对的 HumanEval/19 实际换过位，但没有直接命中。Q8 总计 967 次换入、13 次命中；四道由对转错的题中，两道同样有换位但无直接命中。因此不能把质量变化都归因于新行当轮直接写回：选位、挤占 MASK 或 KV 更新本身也可能改变后续轨迹。哪些效应由直接写入所致，需要[写回开关对照](PROTOCOL.md)。
