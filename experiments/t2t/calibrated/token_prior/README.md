# 单看一个已接受 token 的身份，能否补足位置预测？

**不能作为当前的额外预算分配规则。** 在独立的 24 道校准题上，用每个已知 token 的实际旧位编辑数，除以位置模型对它预测的编辑数，平滑后得到一个查表修正。运行时只使用已接受的 token ID；没见过的 ID 不修正，不读取 logits，也不需要词表投影。模型、平滑和判据在评估前冻结。未调参。

| 名义 Q / 最多旧位席位 | 相同预留席位总数 | 纯位置命中 | 位置 + ID 风险命中 | 逐题更多 / 更少 |
|---|---:|---:|---:|---:|
| 4 / 1 | 452 | 9 | 9 | 2 / 2 |
| 8 / 1 | 710 | 23 | 22 | 1 / 2 |
| 16 / 2 | 1,688 | 56 | 43 | 1 / 7 |

分母均为 LLaDA 原生 frozen30 的 191 个可额外选回的严格编辑事件。Q16 这一档不是单道题造成的下降；7 道题少命中，只有 1 道题多命中。全部 30 题均纳入。这个负例不等于 token 的上下文没有信息：[输入 embedding 与邻近写入的对照](../embedding_context/README.md)和这里只看 token 自身的修正不是同一方法。依照预注册判据，不为查表方案启动真实推理，不报告推测的 TPF 或答题质量。
