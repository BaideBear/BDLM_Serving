# 单个请求：给定这一轮的 Q，哪些工作值得算？

范围：外部给 `step(C)`，不预测下轮预算，不做跨请求调度。不要求第一次拿到整块档。
`C` 是单次 decoder 的物理行上限，不是填充目标。Gemma 必要的 encoder 单独报行数并计入 F。

**如何判断这一轮预算足不足。** 先看本轮必须处理的写入和上下文版本，而不是只看 `C/B`。
Q8 时如果有六个已改 token，只有两行能自由分配；Q64 时如果没有可合法打开的后块，
剩下三十多行也不构成新的采样机会。可以少算、延后或合并同输入同上下文的计算；
不能把没算的行当有效、把本轮采样前的 KV 当作新 token 的 KV，或以草稿替代终检结果。
当前 LLaDA 小档的“冷 MASK 优先吃完所有空位”是待证假设，不是缓存正确性条件。
在 Q8 单独验证用一行重试更早的、已驻留但仍未解的 MASK：置换最右一行冷 MASK，
保留至少一行冷启动，保持前缀剂量、必刷、采样行数和物理宽度在首次交换时相同。
同题同卡配对，不把三题技术验证当作质量结论。

[Q8/Q16 选行审计](../experiments/t2t/serving_slots/controls/llada-slot-allocation/README.md)
另提示一个不同的机会：IBS 也会算**首个 MASK 之后、已解但不欠刷的位置**。
这不是本文所称的物理块内已解前缀。在本方法真实 Q8 状态上重放 IBS 行规则时，差集里
85.56% 的 IBS 独有行属于此类；这不代表这些行本身有 85.56% 的 T2T 率或质量收益。
因此“挪一席只刷这些行”和“同样物理行上也允许编辑”须分开验证。

**Gemma 有一种已经验证的节省不需要牺牲质量。** Q32、单驻留块、无未付写入，按位置
顺序做终检，输入和 self-conditioning 固定。若到当前分片为止每个位置都有终检结果，
并且该片测到第一个真实 EOS，可以停止，不再计算其后的整片。含 EOS 的当片全部计费；
草稿 EOS、其他上下文的 EOS 或前方尚有未验行都不够。全90逐题输出 ID、评分、encoder
输入相同；70 题可省，共省 282 F / 9,024 个 decoder Q。正确数 85→85，宏 TPF
4.669→4.879，TE 14.98%→15.63%。这是固定档单因素，不是其他报价或混合路径的验证。
见 [Q32 配对账本](../experiments/t2t/serving_slots/controls/gemma-factors/verified-eos/q32/cohorts.csv)。

| 本轮状态 | 优先算 | 可以不算 |
|---|---|---|
| 刚降档，未刷写入 ≥ C | 从整个请求的待刷集合中取 C 行，包括已暂停的后块；保留余债 | 普通前缀复看、新开块、在未满足条件的写回上推进采样 |
| 当前块还没建立，或 C 小于 B | 还债后的空位优先取真正尚未建立的 MASK；已建立时保证有可推进 MASK，再交换少量块内干净前缀 | 不做为了启动而超预算的整块预热；不依赖未选行的 logits |
| C 能装下完整头块，头块有可推进位置 | 在预期有收益的阶段取得同一上下文下的完整头块；按模型的合法时钟采样或评估停止 | 不能由“已经投影过”推出“必须采样”；没有下一项合法工作时可空槽 |
| C=2B，可能有合格后块 | 保护头块；按固定可复验的门槛开放相邻后块，已驻留后块必刷不能丢；联合 forward 块内双向，前块不读后块 KV | 不能只为了填满槽位提前开后块，也不能把同轮刚采样的头 token 当作这一轮后块的输入 |
| 头块即将交付或 Gemma 的 encoder 上下文已变 | 完成适配器要求的验证、重建和提交；同输入、同上下文、同一到期动作可尝试与另一项工作合并 | 能省的是重复 forward，不是验证的结果、重建的行或 encoder 的费用 |

**硬约束。** `D` 为包括 M2T、T2T、撤回以及模型规定的状态翻转造成的全请求待刷新行；
以绝对位置记账，不在切档时清空。投影的输入是采样前的 token，不能把这次投影当作
已经刷新刚刚写入的新 token。普通写回不凭空推进采样时钟；已验证的同轮融合例外
要求本来就应采样且行、输入版本、停止条件均有效。冷行不能伪装为已有 KV，
旧 encoder 上下文的行不可伪装为新上下文有效。缓存可近似使用未主动复看的干净行，
不意味着每个 token 不变就必须重算整块。跨块掩码由绝对物理位置决定，不由稀疏行打包顺序决定。

**可调项。** 普通暖轮令 `R = C - min(C, |D|)`。分配上限以 `R` 为母数：
先保至少一个可推进的未解行，再允许从当前严格物理块的已解前缀边缘挑行；
以 `floor(min(B,R)*rho)` 为上限，取不到不回填幽灵行，剩余位置尽可能推进 MASK。
首次投影的冷行、完整头、终检不是这个公式的可选前缀项。`rho` 不是占所有 Q 的固定比例，
也不是预测 T2T 的目标。严格稀疏基准常用 1/8，Gemma Q128 候选用 1/4；尚不能跨模型宣称最优。
例如 LLaDA Q8 有六个必刷时，1/8 规则使剩余两席不给干净前缀；有十二个必刷时本轮付八个，
下轮带四个未付行；不借未来预算。

**用实测划界。**

- [Gemma 各档固定结果及物理账本](../experiments/t2t/serving_slots/controls/gemma-factors/fixed-profile/metrics.csv)：
  Q128 四分之一候选 88/90、宏 TPF 12.794。实际所选 decoder Q 中，普通必刷 50.08%，
  可选干净前缀 5.04%，未解位置 28.70%，终检 16.18%。融合中的必刷只计一次。
- [Gemma 单因素](../experiments/t2t/serving_slots/controls/gemma-factors/README.md)：
  Q256 同分 83/90，稀疏→整头 TPF 19.799→22.940，TE 10.28%→8.21%，
  故多付 Q 可以换少 F，但不代表质量更高。已验证的整头停止再升至 24.252；
  原生为 85/90、25.510。Q256 终检与最后草稿有 22/171 块不同，其中四块会改变下一次 encoder 输入。
  不把草稿直接当最终输出。
- Gemma Q512 晋升后在合格的重建轮合并本来就应发生的采样，90/90 最终序列不变、
  少 58 F；84/90、TPF 23.723，仍低于 W2 的 84/90、25.390。
  相反，在本来仅写回的轮上新增采样，固定 Q32 同剂量实验从 85/90 降到 65/90。
- [Gemma Q512 联合终检](../experiments/t2t/serving_slots/controls/gemma-factors/joint-verify/README.md)：
  在上述重建优化基础上，同轮全头终检并写回驻留后块的欠账；完整 90 题输出逐 token 没变，
  84/90、TPF **24.911**、TE **7.30%**，比上一版再少 81 次 F 和 1,112 个 decoder Q。
  优势主要在少走一轮，不是在少算后块。W2 仍高 0.479 TPF。可切档接口没有放松小预算上限。
- [LLaDA 跨块门槛与只读借位](../experiments/t2t/serving_slots/controls/llada-gate/README.md)：
  原 30 上只读借位在 Q16 同时获益，在 Q8 反而质量和 TPF 都低。
  Q64 立即开后块 17/30、5.494；等到当前块仅剩不超过 1/4 MASK 为 24/30、5.643；
  不是全90结论，也没打过 W2 的 TPF。`2B` 是允许双块，不是要求每轮花 `2B`。

**下一项归因。** LLaDA 原生/Flow W2 对已计算 MASK 的 M2T 阈值是 0.5，而当前
严格执行器/IBS 是 0.9；T2T 保持 0.5。差距不能全归因于行选择。已登记 Q16、Q32 仅头块、
Q64 完整头加 1/4 跨块门槛的 0.9 vs 0.5 配对。两臂保持行计划器、退块方式和
T2T 阈值不变；记录实际测得的提案，自然接受与每块保底分开计，第一处分歧必须是同一
组 logits 上多接受的 MASK。之后不锁轨迹，把新增写入及后续成本都算到最终结果里。
这与 [Q32 块末覆盖/编辑实验](../experiments/t2t/serving_slots/controls/llada-close/README.md)
相互独立，不叠加候选特性。

**判定标准。** 固定预算先报原30、新60、全90的同题结果；分别比较正确数、
逐请求 `N/F` 的算术均值、汇总 `ΣN/Σ读历史KV的decoder Q`。另报 `N,F,Q`、
encoder、成对翻转、失败和真实峰值。TPF 不等同于墙钟加速。没有同时改善的档位保留
为取舍，不通过换题、跨档拼线或改变指标制造单调曲线。等固定档成立，再从相同请求状态
分叉比较不同外部报价，追踪到最终质量与延后的债务，而不是拼接各档平均 TPF。

## 边际一行应该花在哪里

1. **不要为将来的写回强制留空当前的冷启动槽。** Gemma 初建当前块时，扣除
   必刷后尽量访问新行，不采用“每轮最多新建 C/2 行”。在 [270 对同题 GPU 实验](../experiments/t2t/serving_slots/controls/gemma-factors/cold-pacing/README.md)
   上，后者消除了纯冷写回轮，却在 Q32/64/128 每个生成块都多一次冷阶段 forward，
   完成建立前消耗的采样步数则翻倍。Q32 从 85/90 变为 77/90；Q128 从
   88/90、12.794 变为 85/90、11.941。Q64 正确数多一题，但 TPF 略低。保持原冷启动策略。
2. **Q64 可以算两个 LLaDA 块，不等于从一开始就应该算两个。** 相同全头和采样规则下，
   从“有效头块剩余 MASK ≤1/2”推迟到“≤1/4”，正确数 61→70/90、宏 TPF
   5.837→6.279、TE 6.35%→9.14%，每轮平均实际 Q 52.39→45.44。
   [逐行核账](../experiments/t2t/serving_slots/controls/llada-paid-head/row-bill.csv)：
   必刷 Q 47,680→45,153，后块 Q 267,577→141,134（是另一种分组，不能和必刷相加）。
   1/4 组仍有 1,125/2,076 次 T2T 发生在干净的块内前缀。它们不是必须投影的行；
   这也不证明每次编辑都纠正了答案。该组仍低于 Flow W2 的 74/90、10.006。
3. **已经投影和应该采样，是两个决定。** LLaDA 的后块正在冷启动时，已有同轮新 logits
   的暖头 MASK 能低成本推进。固定半块门槛时仅将这些位置送去采样，61→62/90、宏
   TPF 5.837→6.592；原30净增两题、新60净少一题，不能宣称可靠提质。
   这不允许用旧 logits，也不允许在单纯的 KV 写回轮平白推进 Gemma 的采样时钟。
   [1/4 门槛上的独立配对](../experiments/t2t/serving_slots/controls/llada-paid-head/summary-quarter-warm-single-factor.csv)
   已完成：原30 和新60 各净增一题，合计 70→72/90、TPF 6.279→6.979、汇总 TE
   9.14%→9.94%；7 题救回、5 题丢失。与同档历史 IBS64（72/90、4.397、
   14.56%）相比同分、TPF 更高但 TE 较低；与 Flow W2（74/90、10.006）相比两项
   仍落后。结论来自真实组合对照，不是将两个单因素的增量相加。
4. **整头写回是模型和阶段相关的候选，不是普适一致性要求。**
   [LLaDA Q32 原30](../experiments/t2t/serving_slots/controls/llada-close/README.md)
   显示：块末无 MASK 后，从只付写回改为刷新整个头块（不采样）是
   23→26/30、3.945→4.741；相同全头再开放一次编辑仍是 26/30。
   全90上三档依次是 **72、73、74/90**，宏 TPF **4.513、4.812、4.937**，汇总 TE
   **16.62%、14.90%、16.25%**。单次编辑相对只写回是四题救回、三题丢失，不是每次编辑都改善答案。
   新60上只写回相对原法还少两题，不能从原30外推收益。Q32 单次编辑在这套固定题上三项
   点估计都超过 IBS，但尚未打过原生的正确数与 TPF。
5. **预算有富余也应该允许停止。** [Gemma 固定 Q512 最新配对](../experiments/t2t/serving_slots/controls/gemma-factors/single512-stop/README.md)：
   仅在没有驻留后块、相同头块和 encoder 版本的两次连续完整采样后，用实测分数评估原生停止条件；
   停的是额外去噪，不是完整终检、必刷或 encoder。18/90 题提前结束采样，TPF 从
   24.911 到 **25.596**，TE 7.30%→**7.42%**；前后均 84/90、两题输出 ID 改变但均未改变评分。
   固定预算点估计高于 W2 的 84/90、25.390；与原生 Q256 的 85/90、25.510 是不同取舍。
   该配对区间是相对上一版，不是相对 W2。[跨档实测](../experiments/t2t/serving_slots/controls/strict-handle/gemma-single512-stop.json)
   已覆盖 25 种有向报价转移（含同档）；中途改价会清空未完成的停止判断，已触发的停止则保留。
   这是接口语义验证，不是混合预算在 90 题上的质量结论。
6. **放宽 MASK 接受阈值不是“省去冗余计算”。** [LLaDA 固定 Q64，原30](../experiments/t2t/serving_slots/controls/llada-admission/README.md)：
   均为完整头、剩 1/4 MASK 才开后块，T2T 阈值不变；仅将 M2T 从 0.9 放到 0.5，
   宏 TPF 5.643→8.510、TE 8.64%→12.00%，但正确数 24→19，三题救回、八题丢失。
   新增写入和 T2T 会改变后续上下文，即使总 F 和 Q 下降也不能当作等质量收益。
   全90已经完成：70→59/90、6.279→9.317、9.14%→12.36%，六题救回、十七题丢失。
   不采用全局放宽；单独检验只在已经建立的当前头块放宽，并要求高阈值对照精确重放。
   固定 Q16 的同题对照同样 18→16/30。宏 TPF 虽升至 3.220（原 2.494），总
   F 却从 11,175 升至 11,883，输出从 16,978 升至 18,693 个 token；这不是减少工作量。
   Q16 全90：55→42/90，TPF 2.723→3.181，TE 13.45%→14.92%，8 题救回、21 题丢失；
   新60单独是37→26。故小档同样不应全局以降低接受阈值来追求 TPF。

## 小预算的尾块借位

下面是 n164 H4 的完整同卡实验，不是前面 A800 原30 的外推。每个预算固定跑完整请求。
头块照原计划选行；**只有实际剩座**才为相邻块建立 KV，借位当轮不采样后块。
还有已暂停后块的写入欠账时先付欠账，不把它计成借位。各组均为相同 90 个唯一任务，零失败。

| H4 固定档，借位关 → 开 | 原30正确数 | 新60正确数 | 全90正确数 | 全90宏 TPF | 全90 TE | 同档 IBS：正确数、TPF、TE |
|---|---:|---:|---:|---:|---:|---|
| LLaDA Q8 | 9→13 | 20→24 | 29→37 | 1.677→1.610 | 16.22%→16.42% | 69、2.341、28.22% |
| LLaDA Q16 | 18→20 | 37→42 | 55→62 | 2.723→2.887 | 13.45%→17.66% | 73、3.371、20.51% |

目前 Q16 在该候选内部支持只读借位；Q8 是质量与 TPF 的取舍，不是普遍获益。
二者都没有达到同档 IBS，新策略要同 IBS 比，不能只与较弱的内部对照比。
这个差额不只是 IBS 名义窗口与物理 Q 不同造成的。[严格限实算 Q8 的 IBS](../experiments/t2t/serving_slots/controls/llada21-q8-ibs-original-vs-capped.csv)
全90是 72/90、2.364、29.36%；[严格限 Q16 的 IBS](../experiments/t2t/serving_slots/controls/llada21-q16-ibs-original-vs-capped.csv)
是 72/90、3.375、20.54%。这些是同题外部对照，不是更换选行规则的同卡单因素实验。
