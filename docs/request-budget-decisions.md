# 单个请求：给定这一轮的 Q，哪些工作值得算？

范围：外部给 `step(C)`，不预测下轮预算，不做跨请求调度。不要求第一次拿到整块档。
`C` 是单次 decoder 的物理行上限，不是填充目标。Gemma 必要的 encoder 单独报行数并计入 F。

| 本轮状态 | 优先算 | 可以不算 |
|---|---|---|
| 刚降档，未刷写入 ≥ C | 从整个请求的待刷集合中取 C 行，包括已暂停的后块；保留余债 | 普通前缀复看、新开块、在未满足条件的写回上推进采样 |
| 当前块还没建立，或 C 小于 B | 还债后的空位优先取真正尚未建立的 MASK；已建立时保证有可推进 MASK，再交换少量块内干净前缀 | 不做为了启动而超预算的整块预热；不依赖未选行的 logits |
| C 能装下完整头块，头块有可推进位置 | 在预期有收益的阶段取得同一上下文下的完整头块；按模型的合法时钟采样或评估停止 | 不能由“已经投影过”推出“必须采样”；没有下一项合法工作时可空槽 |
| C=2B，可能有合格后块 | 保护头块；按固定可复验的门槛开放相邻后块，已驻留后块必刷不能丢；联合 forward 块内双向，前块不读后块 KV | 不能只为了填满槽位提前开后块，也不能把同轮刚采样的头 token 当作这一轮后块的输入 |
| 头块即将交付或 Gemma 的 encoder 上下文已变 | 完成适配器要求的验证、重建和提交；同输入、同上下文、同一到期动作可尝试与另一项工作合并 | 能省的是重复 forward，不是验证的结果、重建的行或 encoder 的费用 |

**硬约束。** `D` 为包括 M2T、T2T、撤回以及模型规定的状态翻转造成的全请求待刷新行；
以绝对位置记账，不在切档时清空。投影的输入是采样前的 token，不能把这次投影当作
已经刷新刚刚写入的新 token。普通写回不凭空推进采样时钟；已验证的同轮融合例外
要求本来就应采样且行、输入版本、停止条件均有效。冷行不能伪装为已有 KV，
旧 encoder 上下文的行不可伪装为新上下文有效。缓存可近似使用未主动复看的干净行，
不意味着每个 token 不变就必须重算整块。跨块掩码由绝对物理位置决定，不由稀疏行打包顺序决定。

**可调项。** 普通暖轮令 `R = C - min(C, |D|)`。分配上限以 `R` 为母数：
先保至少一个可推进的未解行，再允许从当前严格物理块的已解前缀边缘挑行；
以 `floor(min(B,R)*rho)` 为上限，取不到不回填幽灵行，剩余位置尽可能推进 MASK。
首次投影的冷行、完整头、终检不是这个公式的可选前缀项。`rho` 不是占所有 Q 的固定比例，
也不是预测 T2T 的目标。严格稀疏基准常用 1/8，Gemma Q128 候选用 1/4；尚不能跨模型宣称最优。
例如 LLaDA Q8 有六个必刷时，1/8 规则使剩余两席不给干净前缀；有十二个必刷时本轮付八个，
下轮带四个未付行；不借未来预算。

**用实测划界。**

- [Gemma 各档固定结果及物理账本](../experiments/t2t/serving_slots/controls/gemma-factors/fixed-profile/metrics.csv)：
  Q128 四分之一候选 88/90、宏 TPF 12.794。实际所选 decoder Q 中，普通必刷 50.08%，
  可选干净前缀 5.04%，未解位置 28.70%，终检 16.18%。融合中的必刷只计一次。
- [Gemma 单因素](../experiments/t2t/serving_slots/controls/gemma-factors/README.md)：
  Q256 同分 83/90，稀疏→整头 TPF 19.799→22.940，TE 10.28%→8.21%，
  故多付 Q 可以换少 F，但不代表质量更高。已验证的整头停止再升至 24.252；
  原生为 85/90、25.510。Q256 终检与最后草稿有 22/171 块不同，其中四块会改变下一次 encoder 输入。
  不把草稿直接当最终输出。
- Gemma Q512 晋升后在合格的重建轮合并本来就应发生的采样，90/90 最终序列不变、
  少 58 F；84/90、TPF 23.723，仍低于 W2 的 84/90、25.390。
  相反，在本来仅写回的轮上新增采样，固定 Q32 同剂量实验从 85/90 降到 65/90。
- [Gemma Q512 联合终检](../experiments/t2t/serving_slots/controls/gemma-factors/joint-verify/README.md)：
  在上述重建优化基础上，同轮全头终检并写回驻留后块的欠账；完整 90 题输出逐 token 没变，
  84/90、TPF **24.911**、TE **7.30%**，比上一版再少 81 次 F 和 1,112 个 decoder Q。
  优势主要在少走一轮，不是在少算后块。W2 仍高 0.479 TPF。可切档接口没有放松小预算上限。
- [LLaDA 跨块门槛与只读借位](../experiments/t2t/serving_slots/controls/llada-gate/README.md)：
  原 30 上只读借位在 Q16 同时获益，在 Q8 反而质量和 TPF 都低。
  Q64 立即开后块 17/30、5.494；等到当前块仅剩不超过 1/4 MASK 为 24/30、5.643；
  不是全90结论，也没打过 W2 的 TPF。`2B` 是允许双块，不是要求每轮花 `2B`。

**下一项归因。** LLaDA 原生/Flow W2 对已计算 MASK 的 M2T 阈值是 0.5，而当前
严格执行器/IBS 是 0.9；T2T 保持 0.5。差距不能全归因于行选择。已登记 Q16、Q32 仅头块、
Q64 完整头加 1/4 跨块门槛的 0.9 vs 0.5 配对。两臂保持行计划器、退块方式和
T2T 阈值不变；记录实际测得的提案，自然接受与每块保底分开计，第一处分歧必须是同一
组 logits 上多接受的 MASK。之后不锁轨迹，把新增写入及后续成本都算到最终结果里。
这与 [Q32 块末覆盖/编辑实验](../experiments/t2t/serving_slots/controls/llada-close/README.md)
相互独立，不叠加候选特性。

**判定标准。** 固定预算先报原30、新60、全90的同题结果；分别比较正确数、
逐请求 `N/F` 的算术均值、汇总 `ΣN/Σ读历史KV的decoder Q`。另报 `N,F,Q`、
encoder、成对翻转、失败和真实峰值。TPF 不等同于墙钟加速。没有同时改善的档位保留
为取舍，不通过换题、跨档拼线或改变指标制造单调曲线。等固定档成立，再从相同请求状态
分叉比较不同外部报价，追踪到最终质量与延后的债务，而不是拼接各档平均 TPF。
