# 两模型同一单请求选行规则

**状态：**`7a38ffc` 已淘汰。下文保留其原始设计；当前依据与下一步验证见末节。

2026-11-28。研究目标是**同一算法**，不是为每个模型维护一套策略。此前的 [Live Profile v1](live-profile-v1.md) 保留为独立实测对照，不能用其质量或 TPF 代替这里的结果。

**研究假设（待验证）。** 在给定单请求每轮预算 `q` 下，先偿还已改变输入造成的 KV 欠账，再把剩余 Q 分给推进未解位置和重访可编辑前缀。如果当前块已不能有效利用余量，把相邻后块纳入同一候选集，仍服从物理块因果掩码。前缀重访占用原本可用于解码的 Q，后块过早启动也可能产生因前块更改而作废的计算；两者都要证明自己的收益。模型自带的采样、终止验证和编码不是该方法的贡献，但成本必须计入。

共享的是状态、约束和决策顺序，不是参数值或真实轨迹。等价状态、相同参数的选行一致性只是适配器自检。LLaDA 和 Gemma **独立调参**，不要求从同一预算、同一步或同一类前缀选出相同位置。实际结果应表述为“同一算法，两套公开参数”，不能表述为“一套参数通用”。

## 普通 decoder forward

唯一选行入口为 `bdlm_serving.methods.t2t.unified_rows.plan_rows`。只接收本轮 Q、物理块宽 B、当前块与可选相邻后块的有效范围、未解行、待刷新行、KV 驻留行和后块是否已开。没有模型名、数据集、logits、未来预算或由适配器排好序的候选列表。LLaDA 的 `MASK` 指实际 MASK；Gemma 指未被采样器接受的位置，不是与特定 token ID 做比较。

1. 当前块优先。Q=2B 时可从第一轮开始同时处理两个块；其他档位在当前有效块已全部驻留、未解比例不超过 `open_at` 时可以选到下块。真正选中下块的位置才算开块。一旦打开，降档不丢弃它的状态或欠账。块内双向，跨块只允许后块读前块。
2. 先还已开块所有输入变更欠下的 KV，预算不足就按绝对位置分轮还，不能额外 forward。欠账行本轮只刷新，不重复采样。模型的输入变更必须如实转换为欠账，不能用模型名决定过滤哪些写入。
3. 普通轮余量为 `r`，清洁前缀最多用 `floor(r * prefix_share)`，有未解候选时至少留一格给它。每个块只从本块首个未解行之前选已有 KV 的已解位置，按前缀右端优先，不包含块内不连续的已解岛。其他位置先选当前块的未解行，再选后块；各块先选未建立 KV 的行，再选已驻留的行，同类从左到右。没有合格行就空置，不为填满预算而刷新整块。`2B` 允许完整的双块首轮，不等于承诺之后每轮都正好投影 `2B`。
4. 把去重的绝对行一次性交给 decoder。每个模型的适配器都只执行规划器为**该请求**返回的位置和可采样子集，不许加行、换序重选、追加低阈值接受或按档替换算法。采样、必要验证和编码允许遵照原生接口；所有实际 decoder / encoder forward、验证 Q 和重建 Q 都单独入账。不能将普通选行规则已经统一解读为两个模型的原生状态机完全相同。

切档只换 `q`，不重做 prefill，不丢未支付的写回，也不从将来借 Q。初始对照两个模型都取 `prefix_share=1/8, open_at=1/4`。这些是**候选值，不是实测最优值**。测试档位按 `q/B ∈ {1/8, 1/4, 1/2, 1, 2}` 配对：LLaDA 4/8/16/32/64；Gemma 32/64/128/256/512。

## 固定预算验证顺序

1. 先做执行一致性验证：等价请求状态逐行比较、非零 origin、跨块、降档欠账、2B、终止验证和实际逐层 Q。失败只报错误，不换题或放宽上限。CPU 只可做选行、账本单元测试，不跑推理。
2. 默认参数只作工程锚点。两个模型各自先搜索一个跨五档的常数 `prefix_share`（`0, 1/8, 1/4, 1/2`），保持 `open_at=1/4`；再固定该模型的前缀参数搜索 `open_at`（`0, 1/8, 1/4, 1/2`）。`open_at=0` 仅关掉低预算提前开块，不关掉 2B 双块。两模型分别配对比较，不按某一模型的分数替另一模型选值。报告实际发生的前缀比例、欠账比例、MASK 比例和后块有效产出；整数取整或候选不足导致实际选行相同的档位不是独立效果。先尝试每模型两个常数；只有同一个常数在不同 `q/B` 下出现可重复的系统性失配，才预注册一条简单的 `q/B` 参数函数，不用五档独立冠军拼接成版本。
3. 成对使用同一组筛选题调参，锁定候选后另列确认集；冻结 90 题含原 30，按固定预算提供 90/30 的质量、逐请求平均 `N/F` 和 `ΣN/Σ实际选择读历史KV的decoder Q`。对照原生、同档硬上限 IBS、匹配实际 Q 的 FlowBlock。Q 不匹配时说明口径；未封存的档位不标成 90 题。
4. 只有固定预算验证后才探索预算路径。混合预算得到的数字不能替换任一固定预算点。

**迭代门槛。** 只用于排错或筛选的小样本不能决定版本取舍。任何已经基本确定要继续迭代的版本，必须冻结算法代码、两模型参数表、模型权重、题单/种子、生成上限和评分器，跑完 **2 个模型 × 5 个固定预算 × 同一套 90 题 = 900 条候选请求**。每个格子独立跑满 90 题，并给出相对前一冻结版本和对应基线的质量、TPF、token efficiency 及差值。原生和 Flow 只在对应物理预算处比较；老基线仅在线上记录能核对口径和样例时复用。原 30、新 60、如果参与调参则独立确认子集，分别展示。

按[六卡分片规则](cluster-storage.md)登记 `task_id/seed/prompt_sha256`；相同条件、版本和输入下已完成的小样本才可计入该版本的 90 题。行为或超参发生变化必须另立配置，不拼旧结果。解码本身不收敛按预登记规则记失败；硬件、错误选行或计费错误是无效执行，保留记录并在修复后复验同一题。缺一题就标“未完成”，不按已完成数折算成 90。

**论文主张的判据。** 质量与 TPF 是共同目标，不用加权总分掩盖下降。原生和同档 IBS 是外部对照；内部消融从只还欠账和选 MASK 起步，分别只加前缀、只开后块、二者都开。全部使用同一实际 Q 上限；在 2B 单设只允许当前块的实验对照，不能把 `open_at=0` 当成它。观察配对的改对/改错、每题 `N` 与 `F`（避免误把输出变长当作少做 forward）、后块计算是否进入最终输出；报告分档差值及不确定性。保留“都不加”的可能，不把机制描述为已经胜出。若在冻结 90 上反复调过参，这 90 题是比较集，不是独立泛化证据；投稿的泛化主张需另留未参与选模的数据。
## 淘汰参照后：先保护有效解码前沿

已知证据包括[正式90题](../experiments/t2t/serving_slots/controls/shared-request/formal90/README.md)、[LLaDA 首次出现不同写入的轮次](../experiments/t2t/serving_slots/controls/llada-q4-first-fork/README.md)和 [Gemma 限额 IBS 配对](../experiments/t2t/serving_slots/controls/gemma-factors/ibs-prefix-bridge/README.md)。这些结果能定位现有方法的问题，不能代替下一版的十档成绩。

每轮明确区分三件事：哪些位置实际做投影、其中哪些必须读入上一步改变的 token、其中哪些可以交给模型采样。后两者**可以重叠**，同一行的一次物理投影只算一次。允许已还账的行再编辑时，若它确实改了 token，则下一轮有新欠账。仅仅算出不同的 argmax 不是编辑；应记录实际输入变更、接受状态，以及提交前是否真的再读过该位置。

下一轮把两个变量分开：一个已投影但未解的位置与一个冷 MASK 争最后一个座位时，是否应该重访最左未解位置？保持物理选行不变时，允许已付写回行参加原生编辑是否有用？只有没有挤掉必需写回和当前解码前沿时，才考察干净前缀或后块。这里的“余量”仅表示本轮有空位，不承诺整条请求省计算；以后多算的 F、Q 和改变的输出都要记。没有证据支持默认采用某个刷新比例。

可复用的正对照是 [LLaDA Q4 已投影未解行参与采样](../experiments/t2t/serving_slots/controls/llada-slot-allocation/c4-paid-frozen90.json)。它改变已选 MASK 的采样资格，不是让已解行 T2T，也不是改 Q 的排序。在原活动窗口对照上，90 题 72→74，TPF 1.504→1.571，TE 37.68%→39.88%；TPF 的配对区间为 +0.051 至 +0.084，质量变化区间跨零，且原 30 题 25→23。它支持“不要浪费已投影的未解行”，不证明老窗口内所有动作都应该继承。

`B` 和 `2B` 是同一设计的验收点，不是切换两套解码器。`B` 在同卡上核对原生整块的位置、采样、提交与 encoder 输入；Gemma 在**同一次完整原生去噪**中实测的 argmax，不能用不同时刻拼接而来的历史 argmax 替代。`2B` 与 Flow W2 比较，保留物理块因果性，记录后块哪些输出最终交付、哪些作废，以及重编码和重建。名义预算 `2B`、实算始终只有一块，不构成双块收益。
